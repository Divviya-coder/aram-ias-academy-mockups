The Problem

The ARAM Method

One system. Six movements.

Step 01

Diagnose

Identify the actual weakness before prescribing more study.

Step 02

Learn

Strengthen only the content, concept, example or framework currently required.

Step 03

Write

Translate knowledge into an exam-ready response.

Step 04

Evaluate

Identify the pattern behind lost marks, not only the score.

Step 05

Rewrite

Correct the weakness while the first attempt is still visible.

Step 06

Improve

Measure whether the intervention changed performance.
